# Student Attendance Register

This is an Android app for managing student attendance in schools and colleges.

### Description
The app helps teachers to record and track student attendance easily. Instead of using paper, teachers can mark students as Present or Absent and save the records.

### Features
- Add new students with name and registration number
- Mark attendance as Present / Absent
- View attendance records by date
- Store attendance data locally
- Simple and easy to use interface

### Technology Used
- Android Studio
- Java / Kotlin
- XML for UI design
- SQLite / Room Database for storage

### How to Run the Project
1. Download or clone this repository
2. Open the project in Android Studio
3. Wait for Gradle to sync
4. Connect your Android phone via USB or use Emulator
5. Click Run button to install the app
